# IoT Devices Manager 

A full-stack application for managing IoT devices, collecting measurements in real time, and visualizing data on a web dashboard. 

- **Backend:** Python (Django + DRF), JWT auth, OpenAPI docs, WebSockets (Django Channels), PostgreSQL, Redis. 
- **Frontend:** Angular 16 (standalone), SCSS. 
- **Orchestration:** Docker Compose (backend, db, redis, frontend). 

📺 **Demo video**: `https://drive.google.com/drive/folders/1O-2FtOgS-pC8BWdz0__vqsRs_5jWUtPj?usp=drive_link`

## Prerequisites 

- Docker Desktop (or Docker Engine + Docker Compose plugin) 
- (Optional, for local runs without Docker) 
  - Python 3.12+ 
  - Node.js 18+ 

--- 

## Quickstart (Docker) 

From the repository root: 

```bash 
# 1) Start the full stack (db, redis, backend, frontend) 
docker compose up -d --build 

# 2) Run database migrations 
docker compose exec backend python manage.py migrate 

# 3) (Optional) Seed test data (user, categories, devices, measurements, alerts) 
docker compose exec backend python manage.py create_test_data 
```


Apps & Docs 

Frontend (Angular): http://localhost:4200 

API Docs (Swagger UI): http://localhost:8000/api/docs/ 

OpenAPI schema: http://localhost:8000/api/schema/ 

Healthcheck: http://localhost:8000/api/health 

Authentication (JWT) 

Obtain a token: 

POST http://localhost:8000/api/auth/token/ 
Content-Type: application/json 

{ 
  "username": "testuser", 
  "password": "testpass123" 
} 


Use the access token with: 

Authorization: Bearer <token> 


Refresh: 

POST /api/auth/refresh/ 

API Overview 

Main resources (REST): 

/api/categories/ – CRUD 

/api/devices/ – CRUD, status updates 

/api/measurements/ – CRUD, /aggregate/, /timeseries/ 

/api/alerts/ – CRUD, /resolve/, /reopen/ 

Real-time: 

WebSocket (example): ws://localhost:8000/ws/devices/<public_id>/ 

Events for live measurements/alerts. 

Development (without Docker) – optional 

Backend 

```bash
cd backend 
python -m venv env && source env/bin/activate  # (Windows: env\Scripts\activate) 
pip install -r requirements.txt 
python manage.py migrate 
python manage.py runserver 0.0.0.0:8000 
```


Frontend 

```bash
cd frontend 
npm ci 
npm run start 
# Angular dev server: http://localhost:4200 
```

Proxy to backend is configured under /api.
